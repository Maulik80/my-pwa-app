## 1. Project Overview

**SKPT Cricket** is a mobile-first Progressive Web Application (PWA) demo for managing cricket tournaments, live scoring, and match viewing. The app is designed exclusively for **Phone and Tablet** viewports — desktop/laptop is not supported.

> **Note:** This is a **demo project** — no real database. All data is mock/static. Authentication is simulated with hardcoded credentials.

### Key Characteristics

| Attribute | Value |
|-----------|-------|
| **Type** | Progressive Web App (PWA) — Demo |
| **Target Devices** | Phone & Tablet ONLY |
| **Theme** | Blue + White |
| **Backend** | None — Mock Data (local state) |
| **Auth** | Simulated (hardcoded demo credentials) |
| **Deployment** | Vercel |
| **Offline Support** | Yes (Service Worker + Caching) |
| **Installable** | Yes (Add to Home Screen) |

## 3. Roles & Permissions

### Role Hierarchy

```
SUPER ADMIN (Full Access) — Login Required
    ├── Create/Edit Tournaments
    ├── Create/Edit Teams
    ├── Create/Edit Matches
    ├── Assign Scorers to Matches
    ├── Manage Admin Roles
    └── View Everything

ADMIN (Limited Access) — Login Required
    ├── View Tournaments
    ├── View Teams
    ├── View Matches
    ├── Live Scoring (assigned matches)
    └── CANNOT create tournaments/teams/matches

VIEWER (Read-Only) — NO Login Required
    ├── Dashboard
    ├── Live Matches
    ├── Tournaments
    ├── Points Table
    ├── Teams
    ├── Match Details
    └── NO write access
```

### Login Options

| Role | Login Method | Credentials |
|------|-------------|-------------|
| **Super Admin** | Login Page → Super Admin button | `admin@skpt.com` / `admin123` |
| **Admin** | Login Page → Admin button | `scorer@skpt.com` / `scorer123` |

## 5. Architecture Flow

```
┌─────────────────────────────────────────────────────┐
│                      PAGE                           │
│         (Composition only — no logic)               │
└──────────────────────┬──────────────────────────────┘
                       │ imports
┌──────────────────────▼──────────────────────────────┐
│                   COMPONENT                         │
│         (Actual UI development)                     │
└──────────────────────┬──────────────────────────────┘
                       │ uses
┌──────────────────────▼──────────────────────────────┐
│                    ZUSTAND                          │
│         (Local/UI State + Mock Auth)                │
└──────────────────────┬──────────────────────────────┘
                       │ reads
┌──────────────────────▼──────────────────────────────┐
│                  MOCK DATA                          │
│         (lib/mockData.ts — static JSON)             │
└─────────────────────────────────────────────────────┘
```

### Data Flow Rules

| Rule | Description |
|------|-------------|
| **Pages** | Only render/compose components — NO business logic |
| **Components** | Actual UI development — receive props, emit events |
| **Zustand** | All state — auth, UI, scoring, mock data |
| **Mock Data** | Static TypeScript objects in `lib/mockData.ts` |
| **No API** | No backend calls — everything is local |

## 8. Routing Structure

### Route Definitions

```
/                           → Login Page (MAIN ENTRY)
/login                      → Login Page (same as /)

/super-admin                → Super Admin Dashboard
/super-admin/tournaments    → Tournaments List
/super-admin/tournaments/new → Create Tournament
/super-admin/tournaments/:id → Tournament Detail
/super-admin/tournaments/:id/edit → Edit Tournament
/super-admin/teams          → Teams List

/super-admin/teams/:id      → Team Detail

/super-admin/matches        → Matches List
/super-admin/matches/new     → Create Match
/super-admin/matches/:id    → Match Detail
/super-admin/matches/:id/edit → Edit Match
/super-admin/admin-roles    → Admin Roles Management

/admin                      → Admin Dashboard
/admin/matches             → Assigned Matches List
/admin/matches/:id/score   → Live Scoring Page

/viewer                     → Viewer Dashboard (NO LOGIN)
```

### Role-Based Redirect (After Login)

| Role | Default Route |
|------|---------------|
| Super Admin | `/super-admin` |
| Admin | `/admin` |
